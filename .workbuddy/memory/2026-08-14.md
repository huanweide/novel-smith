### agent-forge 实时多 Agent 控制台（交付给用户的「可见 Agent」诉求）
- 根因：本环境内置子代理（Agent 工具）通道对**用户不可见实时进度**且实测返回空（模型解析空 + deepseek-v4-pro key 无效）。用户多次抱怨「建立不出 Agent、看不到进度」。
- 解法：在 `novel-forge/agent-forge/` 写了一套**真正能跑、能实时显示**的多 Agent 编排控制台（Node 内置 http + SSE，零依赖）：server.js（主代理/编排器，并行调度 5 个真实干活的 Worker Agent）+ agents.js（类型门禁 tsc / 架构体检 / 版本一致性 / 代码质量 / 安全扫描，都是真读 novel-forge 源码）+ public/index.html（暗色仪表盘，Agent 卡片 + 进度条 + 流式日志 + 总报告）。启动：`node server.js`（端口 8787），浏览器开 http://localhost:8787 即可看到 5 个 Agent 实时体检。
- 价值：直接回应「我要看到一堆 Agent 干活、有进度」的诉求；不依赖坏掉的子代理通道。注意 agent-forge 目录**未提交**进 novel-forge 仓库（独立工具，按需提交）。
