# 赞助收款码放置处

本目录用于存放作者收款码图片，**需要你（瑞宝宝）自己放进来**，不随代码生成。

## 你要做的（一次性）

1. 打开微信 → 我 → 服务 → 收付款 → 二维码收款 → 保存收款码图片到手机/电脑。
2. 把图片命名为 `wechat-qr.png`，放进本目录（`public/sponsor/wechat-qr.png`）。
   - 可选：再放一张 `alipay-qr.png`（支付宝收款码），后续若接入可复用。
3. 提交并推送到 GitHub 仓库。

## 放好之后会自动发生什么

- **设置页**：App 内「设置 → 8. 赞助支持」会显示你的微信收款码，用户可扫码赞助。
- **GitHub 主页**：仓库出现 `Sponsor` 按钮，点击跳转到本目录的收款码图片（由 `.github/FUNDING.yml` 配置）。

## 安全说明

- 收款码只是一个「转账入口」二维码，**不含任何密钥 / 账户密码 / 个人信息**，纯静态图片，可放心公开。
- 本目录的 `.png` 会被正常提交到仓库（不在 `.gitignore` 排除范围内）；
  但你的 `.env`、数据库 `data/`、SSH 密钥等敏感文件**不会被提交**，已在上游 `.gitignore` 挡死。

## 还没放图时会怎样

- 设置页会显示占位提示「作者待配置收款码」，不会裂图、不报错。
- GitHub 的 Sponsor 按钮点击后暂为 404，放入图片后即生效。
