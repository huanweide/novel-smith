## 一、一句话结论

网站已经是一条龙能用的「本地零外泄 AI 中文长篇写作系统」。两条护城河——**humanize 去 AI 味本地规则引擎**和**数据本地 SQLite 零外泄**——都已实际落地，且 humanize 已通过「无需配 Key 就能体验」的探测器页打通了新用户的「哇塞时刻」。当前没有阻塞性缺陷，主要短板集中在**运行时无障碍（a11y）动态态**与**接口鉴权**（因产品定位本地自用暂可不急），值得在后续排期里补强。

## 四、a11y 无障碍实测（本次 + 历史）

### 本次实测数据（有证据）
- **静态预渲染三页**（`index.html` / `settings.html` / `detector.html`）经 axe-core 注入 jsdom 实测：**0 结构违规**。
- 补齐项：首页 4 个语义区块 `aria-label` + 设置页 eye 按钮动态 `aria-label` + 修正 `landmark`（首页仅保留一个 `<main>`，避免双 main 重复违规）。
- 三道门禁全过：tsc 0 错 + vitest 1593 全绿 + next build 通过。

### 历史 a11y 工作
- 键盘焦点环可见（v3.1.23）
- 游戏白天模式次要灰字对比度修复（v3.1.24）

### 已知缺口（诚实标注）
1. **运行时动态渲染标签丢失**：`next start` 按需重渲染 async 服务端组件时，aria-label 会丢；但**静态预渲染产物完全正确**（真实静态部署 / Vercel 不受影响）。属部署形态问题，非产品缺陷。
2. **color-contrast 真实对比度**：jsdom 无布局无法计算对比度，需在**真浏览器**（puppeteer + axe）或手工算调色板 WCAG AA。本次静态回归只覆盖了结构规则（region/label/button-name/landmark）。

### v3.1.113 本次对比度修复明细（守卫一上线就抓出来的）

| 主题 | 问题 | 修复 |
|------|------|------|
| `.reader-theme-sepia` 纸感 | `muted #7d6c59` **三面全部不达标**（void 4.40 / abyss 4.17 / surface-3 3.80）；该主题无 `muted-on-surface-3` 兜底变体，前几轮体检漏网 | 加深为 `#706150` → 5.21 / 4.94 / 4.50 |
| `.reader-theme-night` 夜间 | `muted #8b8b98` 浮起面 4.46（差 0.04） | 提亮为 `#8c8c99` → 4.52 |
| `html.azure` 苍青 | `muted #6A807C` 容器面实测 **4.4967**；旧注释写的「4.8:1 达 AA」只对页面底成立，属四舍五入**假达标** | 提亮为 `#6a817c` → 4.54，并订正注释 |

> 结论：**人工标注的对比度不可信，测试才可信**——这三处都是肉眼看不出来、注释还写着「已达标」的坑。
