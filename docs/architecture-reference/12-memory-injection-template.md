# 记忆注入完整模板 — chapter_generate_content

## 注入层级结构

```
## 记忆注入 — 第N章生成上下文

### ▎S级记忆（核心情节脉络 — 必须严格遵循）
[S-1] ...（完整描述 + 影响列表）
[S-2] ...
...

### ▎A级记忆（重要事件 — 影响当前章走向）
[A-1] ...（描述 + 状态）
...

### ▎B级记忆（背景事件 — 低优先级，仅作参考）
[B-1] ...（仅一行摘要）
...

### ▎待兑现事项（Pending Commitments）
[高/中/低优先级] commit-ID：描述（来源，逾期状态）

### ▎主角当前状态档案
姓名/修为/灵根/功法/关键物品/所在地/同行者/心理状态/短期目标/长期目标

### ▎前一章摘要（第N-1章）
一段话概述

### ▎当前章大纲摘要（第N章）
一段话概述 + 本章事件预告
```

## S/A/B 分级规则

| 级别 | 数量上限 | 在prompt中位置 | 注入策略 |
|------|---------|---------------|---------|
| S级 | ≤5条 | 最前，加粗标题 | 必须全文注入，LLM必须严格遵循 |
| A级 | ≤10条 | 中间 | 按"与当前章语义相似度"排序，取top-N |
| B级 | ≤20条 | 最后，标注"仅作参考" | 按时间顺序列出，不加权重强调 |

## 事件选择逻辑

- **S级**: 与当前大纲摘要语义相似度 > 0.7，或逾期 ≥ 2章的待兑现承诺
- **A级**: 相似度 0.4~0.7，或涉及当前章出现的角色/地点
- **B级**: 相似度 < 0.4，但属于同一卷或同一时间线段的背景填充

## 待兑现逾期计算公式

```
逾期章数 = current_chapter_index - commitment_source_chapter_index - expected_fulfillment_gap
```
负数=尚未逾期，正数=逾期章数

## S级事件格式

```
[S-N] 第X章：[事件描述]
      影响：→ [影响1]
            → [影响2]
            → 新增待兑现：[描述]
```

## 主角状态档案格式

```
姓名：[名字]
修为：[境界]（第X章突破）
灵根：[类型]
功法：[名称]（来源）
关键物品：[物品1]（来源）、[物品2]（来源）
当前所在地：[地点]（第X章结束时）
同行者：[人名/无]
心理状态：[描述]
短期目标：[描述]
长期目标：[描述]
```
