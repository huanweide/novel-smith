## 五、AI模型设置面板（在工具箱内）

### 配置层级
```
服务商 → 写作设置 → 高级设置
```

### 模型来源（4种）
| 来源 | 说明 |
|------|------|
| 官网模型 | 使用AI厂商官方API |
| 服务器代理 | 通过服务器转发 |
| 本地模型 | 浏览器本地直连 |
| 自定义配置 | 完全自定义endpoint |

### 本地模型配置
- 模型ID（如 deepseek-v4-flash）
- 显示名称
- API密钥（sk-...，仅存浏览器本地，不上传服务器）
- API地址（如 https://api.example.com/v1）
- 已配置模型列表（可切换，标记"使用中"）

### 安全声明
"本地模型配置仅保存在当前浏览器中。清除浏览器数据、更换浏览器或设备将丢失所有本地模型配置。API密钥仅存储在本地，不会上传到服务器。"
