# I — 游戏模式

> 整合自：16-game-mode
> 边界：只管轮次制互动写作模式。不涉及线性生成流程（→B）、不涉及记忆注入（→C）。
> 最后更新：2026-06-17

---

## 1. 概述

游戏模式是区别于一次性章节生成的**轮次制互动写作**。每回合 AI 写出 500-800 字场景 + 停住 → 生成 4 个选项 → 玩家选择或自定义输入 → 下一回合。

本质上是把"AI 一次写 3000 字"变成"AI + 玩家交替推进，每回合 500-800 字"。

---

## 2. 回合结构

```
第 N 回合：
  AI 写 500-800 字场景（停在关键时刻）
  AI 生成 4 个选项：
    选项1（对应策略A）— 低风险
    选项2（对应策略B）— 高风险
    选项3（对应策略C）— 中风险
    选项4 — 玩家自定义输入
  玩家选择
  → 进入第 N+1 回合，上下文累积上一回合的正文
```

---

## 3. 选项设计——性格罗盘

4 个选项分别对应角色的不同策略维度，同时满足：①符合角色性格 ②走不同行为策略 ③风险等级各异：

| 选项 | 策略标签 | 风险 | 示例 |
|------|---------|------|------|
| 1 | 战术性服软 | 低 | "表面顺从+暗中留后路" |
| 2 | 嘴贱作死 | 高 | "用幽默化解压迫" |
| 3 | 试探底线 | 中 | "理性谈判+身体微对抗" |
| 4 | 暗度陈仓 | 看玩家 | "自定义策略" |

选项前括号标注策略提示，但不暴露难度等级——让玩家自己判断。

---

## 4. 三种控制开关

| 开关 | 效果 |
|------|------|
| 自动完结 | ON = AI 自动判断故事终点并结束游戏 |
| 分解标注 | ON = AI 每回合标注实体追踪（NER 标记） |
| 本地模型 | ON = 使用本地模型而非云端 API |

---

## 5. 实体追踪

每回合追踪：
- `NE|角色名|状态|位置` → 记录角色变化
- `IE|物品名|所有者|状态` → 记录物品转移
- `LE|地点名|特征` → 记录地点变化

---

## 7. 累积机制

```
第1回合：500-800 字
第2回合：500-800 字（上下文 = 第1回合全文 + 大纲 + 角色状态）
第3回合：500-800 字（上下文 = 第1+2回合全文 + 大纲 + 角色状态）
...
最终全章：逐回合累积到 3000+ 字
```

**Token 风险：** 上下文会越来越长。需要独立的内存管理策略——早期回合压缩为摘要注入。
