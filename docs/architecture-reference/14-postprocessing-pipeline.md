# 后处理+蒸馏完整流水线

## 总览（8阶段）

```
chapter_generate_content SSE流结束
  │
  ├─ 第一阶段：文本精修 → chapters.content
  ├─ 第二阶段：事件提取 → story_events（批量INSERT）
  ├─ 第三阶段：突破事件判定 → story_events.is_breakthrough + 主角状态档案
  ├─ 第四阶段：事件分级(S/A/B/C) → story_events.level
  ├─ 第五阶段：待兑现事项 → pending_commitments（条件性INSERT）
  ├─ 第六阶段：主角状态档案更新
  ├─ 第七阶段：蒸馏 → story_review（3层摘要）
  └─ 第八阶段：伏笔关联 → foreshadowing
```

## 第一阶段：文本精修

自动修正：标点半全角、"的的地"混用、分段异常、角色名不一致、重复句

→ 写入 `chapters.content`

## 第二阶段：事件提取

### 判定规则
```
1. 必须有「主体」「动作」「结果」三要素
2. 纯心理活动/环境描写不构成事件
3. 对话若推动剧情发展则构成事件
4. 同一段内多个连续动作合并为一个事件
```

→ 写入 `story_events`（批量INSERT）

## 第三阶段：突破事件判定

### 6条规则
```
1. 修为/境界实质性变化 → 必为突破事件
2. 获得关键功法/血脉/传承 → 必为突破事件
3. 领悟/顿悟 → 突破事件
4. 长期影响标记为S或A级 → 可标记为突破事件
5. 仅战斗经验/普通物品 → 不标记
6. 突破事件必须写入主角状态档案"最近突破"字段
```

→ 写入 `story_events.is_breakthrough` + `主角状态档案.最近突破`

## 第四阶段：事件重要性分级

### S级（永久影响故事走向）
- 主角生死转折（濒死/复活/替死）
- 主角修为跨越大境界（筑基→金丹）
- 关键角色死亡/背叛/黑化
- 世界观核心秘密揭露
- 获得唯一性传承/神器/血脉
- 阵营格局根本性变化

### A级（重要但非根本性转折）
- 主角修为小境界突破（金丹初期→中期）
- 获得重要但不唯一的神通/法宝
- 重要配角出场/退场
- 发现关键线索/地图/信息
- 触发大型支线任务
- 与核心反派第一次正面接触

### B级（推进当前剧情，影响有限）
- 普通战斗胜利/失败
- 获得普通物品/丹药/灵材
- 支线NPC互动
- 场景转换/地图移动
- 情感线小幅推进

### C级（填充性，无长期影响）
- 日常修炼/炼丹/炼器
- 路人NPC对话
- 环境描写/赶路
- 非关键信息获取

→ 写入 `story_events.level`

## 第五阶段：待兑现事项

### 创建条件（满足任意一条）
```
1. 文中出现未解释的悬念
2. 文中出现承诺但未执行
3. 文中出现伏笔的入口但本章未探索
4. 文中出现未完成的约定
5. 事件等级为S级且影响未在本章内收束
6. 新登场重要角色未完成角色弧光
```

### 不创建条件
- 事件已在同一章内闭环
- 只是日常推进，无未兑现信息差

→ 写入 `pending_commitments`

## 第七阶段：蒸馏（三层摘要）

| 摘要层 | 字数 | 视角 | 内容 |
|--------|------|------|------|
| 本章摘要 | 50-100字 | 客观 | 本章实际发生的事件和对话 |
| 主角事件线 | 100-200字 | 第一人称 | 主角完整行动链+关键决策及动机 |
| 支线事件流 | 200-300字 | 旁观者 | 所有角色（含反派/配角）的行动线 |

→ 写入 `story_review`（3个字段）

## 采纳按钮触发流程

点击「采纳」后：
```
① 正文写入 chapter 表
② 章节状态 → complete
③ 蒸馏处理（提取事件→timeline、角色变化→档案、伏笔→foreshadowing、突破事件→入库）
④ 实体一致性检查（新角色/物品自动创建）
⑤ 待兑现事项更新（为下一章准备）
```

## 涉及数据表（7张）

| 表 | 操作 |
|----|------|
| chapters | UPDATE content + status |
| story_events | INSERT 批量 |
| pending_commitments | INSERT 条件性 |
| 主角状态档案 | UPDATE 增量 |
| story_review | UPDATE/INSERT（3字段） |
| foreshadowing | INSERT/UPDATE 条件性 |
| timeline | INSERT |
