## 4. 编辑器底部——实体追踪面板

5 个 Tab：

| Tab | 显示内容 | 高亮颜色 |
|-----|---------|---------|
| 角色 | 正文中出现的角色名，附带快速查看卡片（LRU 缓存） | 蓝色 |
| 势力 | 正文中出现的势力名 | 红色 |
| 场景 | 正文中出现的地点名 | 绿色 |
| 伏笔 | 正文中涉及的伏笔关键词 | 橙色 |
| 物品 | 正文中出现的物品名 | 紫色 |

### 三层实体识别引擎

1. **词典匹配**：AC 自动机（Aho-Corasick），对所有已知实体名做多模式匹配 → O(n) 线性扫描
2. **上下文消歧**：同名实体通过前后文区分（见 D-蒸馏与后处理 消歧策略）
3. **新实体检测**：不在词典中的疑似实体，标记为"待确认"

## 5. 文笔风格面板

### 12 维度参数微调滑块

| 维度 | 范围 | 说明 |
|------|------|------|
| 词汇丰富度 | 0-1 | 低=简单直白，高=华丽丰富 |
| 句子长度 | 10-50字 | 平均句长 |
| 对话比例 | 0-1 | 对话占总文本比例 |
| 描写密度 | 0-1 | 环境/外貌描写占比 |
| 修辞手法 | 0-1 | 比喻/拟人/排比使用频率 |
| 节奏速度 | 0-1 | 低=舒缓，高=紧凑 |
| 心理描写 | 0-1 | 内心独白占比 |
| 环境描写 | 0-1 | 场景氛围渲染 |
| 口语化 | 0-1 | 低=书面语，高=口语 |
| 幽默感 | 0-1 | 调侃/吐槽/黑色幽默 |
| 血腥暴力 | 0-1 | 战斗详细度 |
| 情色暧昧 | 0-1 | 亲密描写程度 |

### 额外参数
- Temperature（0.1-2.0）：创造性 vs 确定性
- 重复惩罚（0-2）：避免重复用词
- 参考经典作家：风格对标
- 禁用偏好词汇：自定义禁用列表

### 10 种预设风格库
古风仙侠 / 现代都市 / 西方奇幻 / 轻小说 / 悬疑惊悚 / 热血战斗 / 文艺抒情 / 幽默搞笑 / 极简留白 / 厚重史诗

### 预览功能
- 实时预览文本框（写一段示例文字，即时看到风格效果）
- 对比模式（左右分栏：修改前 vs 修改后）

## 6. 规则管理界面

12 种规则类型导航（世界观底层/修炼体系/战斗/经济/社会/语言/叙事/角色/伏笔/格式/安全/自定义）。

每条规则的编辑区包含：
- 通用字段：名称、描述、类型、优先级、启用状态
- 类型特有字段：condition（触发条件）、action（处理动作）、scope（作用范围）
- 规则冲突检测：扫描冲突对 → 列出冲突 → 自动/手动解决
- 冲突警告图标：打开规则列表时自动扫描并显示冲突数量

## 7. 大纲编辑器

### 顶部操作栏（20+ 功能按钮）
展开全部/折叠全部、添加卷/章节、上移/下移、缩进/取消缩进、删除、复制、剪切、粘贴、撤销/重做、搜索/替换、AI 生成大纲、导入/导出、模板选择

### 大纲节点操作
- 折叠/展开（单击箭头）
- 拖拽排序（支持跨卷拖拽）
- 右键菜单（26 项操作）

### 5 种大纲模板
| 模板 | 结构 |
|------|------|
| 三幕式 | 建置(25%) → 对抗(50%) → 结局(25%) |
| 起承转合 | 4 段式 |
| 英雄之旅 | 12 阶段 |
| 章回体 | 传统对仗标题 |
| 自由结构 | 用户自定义 |

### 侧边辅助面板
- 统计（字数分布/完成度/节奏分析）
- 图表（结构树可视化）
- 待办（关联的待兑现事项列表）

### AI 大纲生成弹窗
输入作品信息 → AI 自动生成大纲树 → 用户确认 → 一键填入
