# AI写作质量标准（从自我审查反推）

## 废词清单

| 词 | 问题 | 替换策略 |
|----|------|---------|
| 感到 | "告诉而非展示"，隔在读者与体验之间 | 删除，或换具体身体反应 |
| 一阵 | 弱化表达，让情绪模糊无分量 | 换成具体形容词（刺骨的/如潮水般） |
| 不禁 | 网文废词，制造距离感 | 直接写感受本身 |
| 心中/心里 | 反复强调"内心活动"，冗余 | 删除，用身体动作替代 |
| 只见 | "说书人视角"插入语，破坏视角统一 | 删除，直接呈现画面 |
| 然后/但是/随即 | 流水账连接词 | 用句号/破折号制造节奏 |

## 模板化禁用描写

| 模板 | 替换方案 |
|------|---------|
| 心中一惊 | 瞳孔骤缩 / 心跳漏了一拍 / 剑柄硌出冷汗 |
| 身形一闪就消失了 | 如墨入水融入夜色 / 衣袂破风声未散人已不见 |
| 微微一怔 | 眼中掠过一丝怔愣 / 动作顿了一瞬 |
| 感到一阵后怕 | 手在微微发抖 / 后背被冷汗浸透 |

## 六维质量标准

| 维度 | 标准 |
|------|------|
| 废词率 | 每千字≤3-5个废词 |
| 展示vs告诉 | 80%以上情感用具体动作/感官描写传递 |
| 视角统一 | 选定视角后不插入全知评论（如"只见"） |
| 句式节奏 | 避免连续"主谓宾+连接词"流水账，用句号和破折号打破节奏 |
| 动作描写 | 禁止"身形一闪""心中一惊"等磨损模板，每次用独特描写 |
| 逻辑一致性 | 动作与神态不自相矛盾（如"一怔"+"更快"） |

## 审查流程（每200字触发）
1. 扫废词 → 标记替换
2. 扫句式 → 检测连续"主谓宾+连接词"模式
3. 扫模板 → 匹配磨损表达库
4. 扫视角 → 检测"只见/只见得/却见"等全知插入
5. 扫逻辑 → 语义冲突检测

## 修改原则
- 砍连接词，用破折号和句号制造节奏
- "转身一看" → "回身"
- "但是X动作更快"（上帝视角评论）→ 直接呈现结果
- 保持第三人称有限视角（读者=苏月的眼睛）
