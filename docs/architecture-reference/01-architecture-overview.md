# 云笔AI小说写作助手 — 完整架构逆向工程

## 技术栈
- **前端**: Vue 3.5.30 + Vite + Tailwind CSS + Remix Icon
- **状态管理**: Pinia
- **路由**: Vue Router (分包加载)
- **主题**: 暗色系, CSS变量驱动
  - `--primary: #8b5cf6` (紫色)
  - `--bg-main: #020617` / `--bg-dark: #0f172a` / `--bg-card: #1e293b`
  - `--text-primary: #f8fafc` / `--text-secondary: #94a3b8` / `--text-muted: #64748b`
  - `--border: #334155`

## API 设计模式
```
RESTful + 流式代理
├── 数据API: /api/{module}/{action}
│   统一响应: {success: bool, data: any, message: str}
├── AI代理: /api/stream (POST → 转发至DeepSeek/硅基流动)
│   请求体: {端点URL, API密钥, 请求体: OpenAI兼容格式}
├── 心跳: POST /api/heartbeat
├── 认证: GET /api/auth/profile
└── 消息持久化: POST /api/messages
```

## Agent模式 vs 普通模式
| 维度 | 普通模式 | Agent模式 |
|------|--------|---------|
| API mode值 | `""` | `"Agent"` |
| 能力 | 自由对话+写作 | 可调用58个工具操作项目数据 |
| placeholder | "输入你的需求..." | "告诉AI你想对项目做什么..." |
| 回复方式 | 纯文本 | 工具调用 + 结构化表格 |
| system prompt | 通用写作助手 | 包含项目上下文+工具列表 |
