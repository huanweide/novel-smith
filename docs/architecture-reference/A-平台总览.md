## 1. 总架构

```
前端界面（Vue 3 + Vite / 本项目用 Next.js 16 + React 19）
    ↓ 用户操作
AI Agent 层（理解意图 → 调用工具 → 返回结果）
    ↓ 工具调用
业务逻辑层（查/增/改/删 → 数据持久化）
    ↓ 读写
数据库层（15+ 张表）
```

三层职责分明：
- **前端**：只管展示和用户交互，不含业务逻辑
- **Agent**：接收自然语言指令，解析意图，调度工具，组合结果返回
- **后端**：执行 CRUD，运行蒸馏引擎（不调大模型），调用大模型 API（仅正文生成）

## 4. 核心设计哲学

六条原则贯穿整个系统：

1. **一次性加载，一次调用，流式返回**：上下文只构建一次，全章一次生成，Token 只消耗一次
2. **蒸馏不调 API**：本地正则/NER/关键词/状态对比，1-3 秒完成，零 API 消耗
3. **时间线感知**：跳章写时不污染上下文，按章节序号过滤记忆
4. **按需加载，用完即弃**：数据只在需要时从数据库加载，不常驻上下文
5. **数据库是唯一真相源**：Agent 每次从数据库重读最新数据，不依赖对话缓存
6. **最难的不是代码，是领域规则**：命名模式库、消歧策略、伏笔触发词——这些是中文网文领域的专业知识
