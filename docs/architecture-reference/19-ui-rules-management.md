# 规则管理界面 — 完整交互设计

## 入口
设置 > 规则管理 / 世界Tab > 设定分类 > 规则管理

## 一、规则类型导航（12种）

| 类型 | 说明 |
|------|------|
| 世界观底层规则 | 世界运转根本法则（天道、物理） |
| 修炼体系规则 | 境界划分、突破条件、修炼速度 |
| 战斗规则 | 战力计算、伤害判定、克制关系 |
| 丹器符阵规则 | 炼丹/炼器/制符/布阵成功率与效果 |
| 经济规则 | 灵石体系、物价、交易规则 |
| 势力规则 | 宗门晋升、势力战争、外交规则 |
| 社交规则 | 好感度、忠诚度、仇恨值 |
| 地理规则 | 区域灵气浓度、禁地法则、传送限制 |
| 时间规则 | 时间流速、寿命计算 |
| 概率规则 | 奇遇概率、掉落概率、事件触发概率 |
| 禁忌规则 | 天道禁忌、不可触碰的底线 |
| 自定义规则 | 用户自行添加 |

## 二、规则列表区

- 添加规则 / 批量导入规则(JSON/YAML) / 批量导出规则
- 搜索（按名称/关键词）
- 筛选（按状态/优先级/标签）
- 排序（按名称/优先级/创建时间/修改时间）

### 单条规则操作
- 开关（启用/禁用）
- 优先级标识（高/中/低）
- 拖拽调整执行顺序
- 右键菜单：编辑/删除/复制/启用/禁用
- 复选框（批量操作）

## 三、规则编辑区

### 通用字段
名称 / 分类 / 优先级(高/中/低) / 开关 / 标签 / 描述(富文本) /
规则公式/参数（代码式输入，如 `突破概率 = 基础值×灵根系数×丹药加成`） /
适用对象（全体/仅主角/仅NPC/仅特定势力） /
触发条件（条件式输入，如 `当境界≥金丹且灵石≥10000时`） /
生效范围（全局/当前卷/当前章/特定地点） /
冲突处理（高优先级覆盖/取平均值/叠加） /
备注 / 关联设定/角色/章节 / 版本历史

### 各类型特有字段
- 修炼体系：大境界列表 / 小境界数 / 突破所需灵气 / 突破失败惩罚 / 寿元加成
- 战斗规则：攻击力公式 / 防御力公式 / 暴击率 / 闪避率 / 属性克制表
- 经济规则：基础货币 / 兑换比例 / 通货膨胀率 / 交易税
- 丹器符阵：成功率公式 / 材料消耗 / 品质浮动范围
- 社交规则：好感度增减公式 / 仇恨值阈值 / 忠诚度衰减速度

## 四、规则冲突检测
- 冲突检测（扫描所有已启用规则）
- 冲突列表（列出冲突对+原因）
- 自动解决（按优先级）
- 手动解决（逐条选择保留）
- 冲突警告图标⚠️
