# 大纲编写界面 — 完整交互设计

## 入口
项目Tab > 大纲视图 / AI工具 > 大纲生成 / 编辑器 > 大纲模式

## 一、顶部操作栏

| 按钮 | 说明 |
|------|------|
| 添加卷/章/节 | 新建大纲节点 |
| 批量添加 | 多行标题→自动创建多章节 |
| 导入大纲 | OPML/JSON/Markdown/TXT |
| 导出大纲 | OPML/JSON/Markdown/TXT |
| AI生成大纲 | 输入主题→AI生成完整大纲 |
| AI扩写大纲 | 选中章节→AI扩写子章节 |
| AI优化大纲 | 结构优化建议 |
| 拖拽模式开关 | 开启/关闭拖拽排序 |
| 整理编号 | 自动重新编号 |
| 展开全部/折叠全部/展开到指定层级 | 层级控制 |
| 大纲筛选 | 按状态：全部/待写/写作中/已完成/弃稿 |
| 大纲搜索 | 按标题关键词搜索 |
| 显示选项 | 字数/状态标签/摘要/编号/层级线/进度条/目标字数/创建时间/修改时间/备注图标 |
| 密度模式 | 紧凑/舒适/大号 |
| 撤销/重做 | 大纲修改的撤销重做 |
| 自动保存状态 | 状态指示器 |

## 二、大纲节点操作

### 每节点显示元素
折叠三角 / 拖拽手柄 / 层级线 / 编号 / 标题(双击编辑) / 状态标签 / 字数标签(当前/目标) / 进度条 / 备注图标📌 / 锁定图标🔒 / AI标识🤖 / 复选框

### 右键菜单（26项）
- 编辑章节 / 重命名 / 编辑摘要 / 设置目标字数 / 添加备注
- 添加子章节 / 插入上方 / 插入下方
- 复制 / 剪切 / 粘贴 / 粘贴为子节点
- 删除 / 上移 / 下移 / 升级 / 降级 / 设为卷/章/节
- 标记状态（待写/写作中/已完成/弃稿）
- 锁定 / 解锁
- AI写作 / AI扩写摘要 / AI生成内容
- 查看章节 / 查看版本历史 / 导出单章
- 复制标题 / 复制路径

## 三、批量操作（勾选多节点后）

批量删除 / 批量移动 / 批量标记状态 / 批量设置目标字数 / 批量AI写作 / 批量导出
全选 / 取消全选 / 反选 / 选择同级 / 选择子节点

## 四、侧边辅助面板

- 大纲统计（总卷数/总章数/总字数/已完成数/待写数）
- 写作进度概览（环形图/柱状图）
- 章节字数分布图
- 最近修改列表
- 待办事项列表

### 大纲模板（5种）
| 模板 | 结构 |
|------|------|
| 三幕式 | 建置(25%)→对抗(50%)→结局(25%) |
| 起承转合 | 4段式传统结构 |
| 英雄之旅 | 12阶段（平凡世界→历险归来） |
| 章回体 | 传统对仗标题章回体 |
| 自由结构 | 仅卷层级，自由填充 |

## 五、AI大纲生成弹窗

- 主题输入框 / 类型选择 / 篇幅选择（短/中/长/超长）
- 节奏选择（紧凑/均衡/舒缓）
- 包含元素（系统流/重生/穿越/后宫/无敌流/升级流等，多选）
- 参考作品 / 生成 / 重新生成 / 调整后生成
- 预览大纲（弹窗内预览）
- 应用大纲 / 部分应用 / 导出大纲

## 六、章节摘要编辑弹窗

- 标题（展示） / 摘要编辑区（富文本）
- 字数目标 / 关键事件（标签输入）
- 出场角色（关联选择器） / 涉及地点 / 涉及伏笔 / 涉及物品
- 情绪基调（紧张/轻松/悲伤/激昂/悬疑/温馨）
- AI扩写摘要 / AI润色摘要
- 保存 / 取消

## 七、底部状态栏

总卷数 / 总章数 / 总字数 / 已完成 / 完成度(进度条) / 待写章节数 / 今日写作字数
