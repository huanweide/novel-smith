# 游戏模式（Game Mode）— 互动文本冒险写作

## 概述

传统的 `chapter_generate_content` 是"AI一次性生成整章→用户审核采纳"。游戏模式是**回合制互动写作**——AI写一段就停，给4个选项让用户选主角下一步做什么，选完继续写。

**触发方式**：点击大纲章节右侧的 🎮 游戏模式按钮（`ri-gamepad-line` 图标，与 AI写作 `ri-magic-line` 并列）

## 界面布局

```
┌─ 顶栏 ─────────────────────────────────────────────┐
│  游戏模式 - 《XXX》第N章 XXX                         │
│  [自动完结] [分解标注] [本地模型]   轮次 N            │
├─ 左侧栏 ──┬── 主区域(正文流) ─────┬── 右侧栏 ──────┤
│ 情节       │                      │ 正文/背包/世界  │
│ 角色       │  [触发动作]           │ 正文进度 N/3000 │
│ 势力       │  AI生成的段落          │                │
│ 地图       │  ===新实体===         │                │
│            │  ===角色物品变动===     │                │
│ 情节进度N% │                      │                │
│            │  4个编号选项           │                │
│            │  (按键快速选择)         │                │
├────────────┴──────────────────────┴────────────────┤
│ 底部动作栏: [观察][对话][战斗][探索][使用物品][休息]  │
│ 底部控制: [回退] [自动推进] [结束并导出]               │
└───────────────────────────────────────────────────┘
```

## 游戏循环

```
用户选择动作(6个按钮之一 或 编号选项1-4)
  → POST /api/ai/local/stream
  → AI 流式生成~400-600字
  → AI 自动检测新实体(NE|...)
  → AI 追踪物品变动
  → AI 生成4个新选项
  → 轮次+1, 字数累计
  → 等待下一次用户选择
  → ... 重复直到3000字或结束
```

## 6个动作按钮

| 按钮 | 功能 | AI行为 |
|------|------|--------|
| 观察 | 仔细观察环境/人物 | 描写环境细节、隐藏线索、人物特征 |
| 对话 | 与角色交谈 | 推进对话线、揭示信息、触发NPC互动 |
| 战斗 | 进入战斗 | 生成战斗场景、判定胜负 |
| 探索 | 移动/探索新区域 | 展开新场景、发现新地点/物品 |
| 使用物品 | 使用背包物品 | 基于已有物品生成剧情，选项引用具体物品名 |
| 休息 | 休息/恢复 | 时间推进、状态恢复、可能触发突发事件 |

## 选项系统

每轮生成后 AI 给出 4 个编号选项（支持键盘数字键快速选择）。选项类型：

- **方向性选项**：改变场景/行动路线
- **策略性选项**：面临抉择，不同后果
- **物品驱动选项**：使用特定物品相关行动（点"使用物品"后出现）
- **角色交互选项**：与当前场景人物互动

## 3个开关

| 开关 | 推测功能 |
|------|---------|
| 自动完结 | 开启后，达到3000字自动结束章节 |
| 分解标注 | 开启后，自动将正文拆解为结构化标注（实体/事件/伏笔） |
| 本地模型 | 切换为本地部署的AI模型（离线模式） |

## 实体追踪

每轮生成后自动输出：

```
===新实体===
NE|实体名1
NE|实体名2
```

检测类型：角色、地点、物品、声音/现象、组织结构。新实体可能自动加入项目实体库（角色/物品/场景表）。

## 物品变动追踪

```
===角色物品变动===
获得×1：急救绷带
消耗×1：饮用水
```

每轮追踪背包增减。物品来自正文中主角获得/使用的物件。

## 右侧栏——3个Tab

### 正文 Tab
- 累积正文实时显示
- 进度条：N / 3000 字
- 预估阅读时间

### 背包 Tab
- 当前拥有的物品列表
- 物品来源标注（哪一轮获得的）
- 初始为空（"背包空空如也，在冒险中获取物品吧"）

### 世界 Tab
- 世界观/场景状态展示
- 当前所在位置描述

## 左侧栏

| 面板 | 内容 |
|------|------|
| 情节 | 情节进度百分比 + 情节点列表 |
| 角色 | 当前章节涉及的角色 |
| 势力 | 涉及势力 |
| 地图 | 场景地图/位置关系 |

## 控制按钮

| 按钮 | 功能 |
|------|------|
| 回退 | 撤销上一轮，恢复到选择前的状态（支持多次回退） |
| 自动推进 | AI自动随机选择选项，无需手动点击 |
| 结束并导出 | 结束游戏模式，将累积正文保存为章节 |

## API

```
POST /api/ai/local/stream
```

请求体应包含：
- 当前大纲节点ID
- 用户选择的动作类型（观察/对话/战斗/探索/使用物品/休息 或 选项编号）
- 游戏状态上下文（轮次、已有的实体列表、背包内容、累积正文）
- 3个开关状态

响应格式：SSE流式（同 chapter_generate_content），但事件类型更简化——主要推送 token 事件 + 生成完成后的实体/物品标记。

## 与 chapter_generate_content 的核心区别

| 维度 | 写作面板模式 | 游戏模式 |
|------|------------|---------|
| 生成粒度 | 整章一次生成 | 逐段回合生成 |
| 用户参与 | 生成后审核 | 每轮选择驱动 |
| 内容结构 | 线性叙事 | 分支叙事 |
| 字数控制 | 一次性目标 | 渐进式累积(3000字上限) |
| 实体管理 | 后处理阶段统一提取 | 每轮实时追踪 |
| 物品系统 | 无 | 有（背包+使用） |
| 轮次/选项 | 无 | 4选项/轮 |
| 适用场景 | 有完整大纲 | 探索式/自由发散写作 |
