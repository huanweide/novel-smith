# 蒸馏系统 — AI写作助手的记忆引擎

## 概述

蒸馏 = 从AI生成的原始章节正文中，自动提取结构化关键信息，存入数据库表。

> 类比：原始正文=原油 → 蒸馏=炼油 → 汽油(事件记录)+柴油(角色状态)+航空煤油(伏笔更新)

## 完整蒸馏流程

```
用户点击"采纳"
  ↓
① 正文解析 (分段+NER实体识别+事件边界检测)
② 事件提取 (三要素：谁→角色ID / 做了什么→事件描述 / 结果→状态增量)
   分类：主线/角色弧线/支线
③ 状态变更检测 (修为/心境/关系/物品/位置变化)
④ 伏笔状态评估 (新埋→创建 / 回收→更新status / 强化→更新description)
⑤ 入库 (event_history/timeline/character/foreshadow/item/power_breakthrough)
  ↓
蒸馏完成 → 数据供下章生成调用
```

## 触发时机

| 时机 | 行为 |
|------|------|
| 用户点"采纳" | 完整蒸馏 |
| 点"重新生成" | 不蒸馏，丢弃 |
| 手动修改后保存 | 增量蒸馏 |
| 批量多章 | 逐章蒸馏，顺序执行 |

## 待兑现事项追踪

### 来源
- 显性伏笔 (foreshadow status="已埋设")
- 角色承诺 (event_history中的"承诺类"事件)
- 未完成行动 (中断事件)
- 未解答谜题 (story_core核心悬念)
- 未发生约定 (timeline中的未来事件)

### 生命周期
```
创建 → 待机(注入prompt提醒) → 兑现/回收 → 超时废弃
```

### 优先级 = 紧急性 × 重要性

**紧急性**: 当前章=10 / 3章内=7 / 10章内=4 / 不限=1
**重要性**: 主线核心=10 / 角色弧线=7 / 支线=4 / 彩蛋=1

## 主角状态档案 (JSON)

```json
{
  "修为状态": {"当前境界": "筑基中期", "突破进度": "78%"},
  "身体状态": {"生命值": "健康", "伤势": [], "特殊状态": []},
  "心境状态": {"当前情绪": "坚定", "心魔": null, "执念": "", "道心稳固度": "85%"},
  "装备物品": {"法宝": [...], "丹药": [...], "灵石": "..."},
  "人际关系": {"师父": "", "好友": [], "敌人": [], "暧昧": ""},
  "当前位置": {"地点": "", "所属势力": "", "最近移动": ""},
  "最近事件摘要": ["第N章: ..."]
}
```

每次蒸馏后: diff新旧状态 → 逐字段更新 → 版本控制(保留3次快照)

## 分层故事回顾 (三层金字塔)

```
      S级(核心,3-5条) ← 必须注入
    A级(关键,10-15条) ← 重要注入
  B级(普通,不限) ← 压缩摘要
```

### 分级算法
```python
score = 时效性分(max(0,10-chapter_diff*0.5))
      + 事件类型分(突破20/死亡25/传承15/战斗5/日常1)
      + 伏笔关联分(埋设15/回收20)
      + 角色重要性分(主角10/反派8)
# score>=40→S, >=20→A, else→B
```

## 突破事件自动识别

### 四维检测
1. **关键词匹配**: 突破/晋级/渡劫/顿悟 + 境界名称 + 动作描述 + 异象描述
2. **修为状态对比**: diff前后"当前境界"字段
3. **能量阈值检测**: "灵力暴涨"等+力量体系对照
4. **因果链条检测**: 前提条件+过程+结果

### 分类
| 类型 | 判定 | 入库动作 |
|------|------|----------|
| 大境界突破 | 跨越大境界 | 创建事件+更新境界+异象记录 |
| 小境界突破 | 同境界小阶 | 创建事件+更新境界 |
| 特殊突破 | 非修为质变 | 创建事件+更新心境 |
| 伪突破 | 失败 | 创建事件+更新伤势 |

## 长期记忆衰减

| 信息类型 | 保留策略 |
|----------|----------|
| 核心悬念 | 永不衰减 |
| 主角境界 | 永久保留 |
| 重要物品/角色关系 | 永久保留 |
| 最近事件 | 保留20章 |
| 日常事件 | 保留10章→压缩摘要 |
| 已完成支线 | 仅保留标题+结论 |
| 过期伏笔 | 标记废弃 |

## 数据库核心表

```
projects
├── worldviews (1:1)
├── outlines (树形: volume→chapter)
├── chapters (正文, 关联outline)
├── characters (含status_archive JSON字段)
│   └── character_relations
├── event_history (含importance S/A/B分级 + state_delta JSON)
├── timelines
├── foreshadows (状态流转: 未埋设→已埋设→已回收→已废弃)
├── pending_commitments (待兑现内部表)
├── power_breakthroughs
├── items
├── factions
├── power_systems
└── skill_systems
```

## 数据循环
```
生成N章→采纳→蒸馏→更新DB→N+1章生成时
→记忆注入层加载(待兑现+状态档案+分层回顾+时间线+物品+关系)
→注入prompt→AI生成N+1章→...
```
