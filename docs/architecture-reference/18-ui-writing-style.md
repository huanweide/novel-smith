# 文笔风格界面 — 完整交互设计

## 入口
设置 > 文笔风格 / AI工具 > 文笔风格设置 / 编辑器底部风格切换器

## 一、风格选择区

### 预设风格库（10种）
古风仙侠 / 现代都市 / 西方奇幻 / 轻小说 / 悬疑惊悚 / 热血战斗 / 文艺抒情 / 幽默搞笑 / 极简留白 / 厚重史诗

### 操作
- 风格搜索（按名称/关键词）
- 风格筛选（系统预设/我的收藏/我的自定义）
- 风格排序（按名称/使用次数/最近使用）
- 风格收藏星标（置顶常用风格）
- 风格悬停预览（显示详细说明）

## 二、参数微调区（12维度滑块）

| 维度 | 范围 | 说明 |
|------|------|------|
| 词汇丰富度 | 1-10 | 简单词汇 ↔ 生僻辞藻 |
| 句子长度 | 1-10 | 短句为主 ↔ 长复合句 |
| 描写密度 | 1-10 | 极简叙事 ↔ 浓墨重彩 |
| 对话比例 | 1-10 | 少对话多叙述 ↔ 对话驱动 |
| 修辞手法 | 1-10 | 平实直述 ↔ 大量比喻排比拟人 |
| 节奏速度 | 1-10 | 舒缓悠长 ↔ 紧凑急促 |
| 心理描写 | 1-10 | 外聚焦 ↔ 内心戏丰富 |
| 环境描写 | 1-10 | 写意略写 ↔ 工笔细描 |
| 口语化程度 | 1-10 | 书面语 ↔ 完全口语 |
| 幽默感 | 1-10 | 严肃正经 ↔ 诙谐幽默 |
| 血腥/暴力 | 1-10 | 含蓄 ↔ 直白描写 |
| 情色/暧昧 | 1-10 | 隐晦 ↔ 露骨 |

### 额外参数
- Temperature (0-2)
- 重复惩罚 (0-2)
- 参考经典作家（多选：金庸/古龙/刘慈欣/村上春树/J.R.R.Tolkien等）
- 禁用词汇（标签输入）
- 偏好词汇（标签输入）
- 句式偏好（无偏好/多用排比/多用设问/多用短句）
- 人称视角（第一/第三人称有限/第三人称全知）
- 时态（过去/现在）

## 三、预览区
- 预览文本框（当前风格示例）
- 更换示例（随机切换）
- 输入自定义文本测试 → AI按当前风格重写
- 对比模式（左右分栏：原风格 vs 调整后风格）
- 刷新预览

## 四、管理区
- 保存为自定义风格
- 覆盖保存 / 另存为新风格
- 重命名 / 删除
- 设为默认文笔
- 应用到当前章节/整卷/整个项目
- 导出风格(JSON) / 导入风格(JSON)
- 分享风格（链接/代码）
- 重置为默认
- 查看使用历史

## 五、底部操作
确认 / 取消 / 应用（不关窗直接应用）
