# UI层 — 实体追踪系统与写作面板实现

## 一、5个实体Tab

### Tab结构
编辑器底部面板：角色(计数) / 势力 / 场景 / 伏笔 / 物品

### 数据来源（3层合并）
1. 第一层：当前章节正文前端NER实时提取
2. 第二层：event_history 表中本章涉及记录
3. 第三层：项目全部实体（仅计数，不展开详情）

### 实时更新
```
用户打字 → 防抖500ms → 前端轻量NER → 更新Tab计数(1-5ms本地)
用户点击Tab → 请求后端API → 渲染完整Tab内容(50-200ms网络)
```

## 二、实体识别架构（3层引擎）

### 第一层：本地字典匹配（0延迟）
- 前端内存维护"项目实体字典"（角色名/势力名/地名/物品名）
- 算法：AC自动机（Aho-Corasick），O(n+m)
- 项目加载时从 `GET /api/projects/{id}/entity-dictionary` 获取

### 第二层：上下文消歧
- "清虚" → 角色ID=2 or 地点"清虚洞府"?
- 滑动窗口（前后50字）提取上下文特征判断

### 第三层：新实体检测
- 检测不在字典中的陌生名词
- 提示用户"检测到新角色'李四'，是否添加到项目？"

### 同步机制
用户新增实体 → WebSocket推送 → 前端增量更新自动机（无需重建）

## 四、AI写作面板UI

### 弹窗结构
```
┌─ 顶部工具栏 ─────────────────────────────────┐
│  [稳定模式▼] 字数:[2500] 风格:[默认]          │
│  [🔄重新生成] [💾采纳] [📋复制] [🔍对比]     │
├─ 主内容区（流式渲染） ────────────────────────┤
│  第五章 突破瓶颈                               │
│  苏月盘膝坐在密室之中... ▌ ← 光标闪烁         │
├─ 底部状态栏 ────────────────────────────────┤
│  ⏳ 已生成342/2500字 | 预计剩余15秒           │
│  ████████░░░░░░░░░░░ 34%                      │
│  注入: [✔记忆] [✔状态] [⏳分层回顾...]        │
├─ 侧边栏（可折叠） ──────────────────────────┤
│  大纲摘要 | 前章结尾 | 待兑现事项 | 关联实体  │
└──────────────────────────────────────────────┘
```

### SSE流式渲染
技术选型：SSE (Server-Sent Events)，单向通道
端点：`GET /api/chapters/generate-stream?outline_id=5`

事件流：
```
event:start → event:memory(loading/done) → event:generation_start
→ event:token(content="苏") → event:token(content="月") → ...
→ event:done(stats)
→ event:distillation_start → distillation_progress → distillation_done
```

### 前端渲染优化
- 防抖合并：每50ms刷新一次DOM（不是每token刷）
- 虚拟化渲染：只渲染可见区域，视口外使用占位符
- 自动滚动到底部

## 五、通信架构

| 方式 | 用途 | 占比 |
|------|------|:----:|
| REST API | 查询/创建/修改（90%操作） | 主要 |
| SSE | 正文生成流式渲染 | 生成时 |
| WebSocket | 实体字典更新推送 + 实时协作 | 辅助 |

### Agent模式交互
```
用户消息 → REST/WS → Agent Runtime分析意图
→ 调用工具(查询DB/调用LLM/写数据)
→ 如需生成正文 → SSE流式推送
→ 如不需生成 → 直接文本响应
```

## 六、三层自动保存

### 第一层：LocalStorage（500ms防抖）
- 防浏览器崩溃，每次按键后500ms自动保存草稿
- 恢复时提示"检测到未保存的草稿"

### 第二层：服务器自动保存（3秒防抖）
- `PATCH /api/chapters/{id}` 增量更新
- 版本号递增 + 乐观锁冲突处理

### 第三层：手动保存（Ctrl+S）
- 触发蒸馏引擎（仅当明确"保存并蒸馏"）
- 保存成功显示"已自动保存"
