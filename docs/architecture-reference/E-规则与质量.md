## 1. 规则系统架构

### 规则定义结构

每条规则包含：
```
{
  id, name, description, type,
  condition: "触发条件（正则或关键词）",
  action: "违反后的处理（警告/拒绝/自动修正）",
  scope: "global" | "volume" | "chapter_range" | "event_type" | "character_scene" | "conditional",
  scopeConfig: Json,        // 范围的详细配置
  priority: 1-10,            // 基础权重
  specificityScore: 1-6,    // 特异性评分
  enabled: boolean
}
```

### 12 种规则类型

| 类型 | 说明 |
|------|------|
| 世界观底层规则 | 物理法则、灵力规则等不可违背的设定 |
| 修炼体系规则 | 境界突破条件、功法限制 |
| 战斗规则 | 战力差距、招式限制 |
| 经济规则 | 物价体系、货币兑换 |
| 社会规则 | 宗门礼仪、辈分尊卑 |
| 语言规则 | 禁用词、禁用句式 |
| 叙事规则 | 视角限制、信息差 |
| 角色规则 | OOC 检测、性格一致性 |
| 伏笔规则 | 埋设/回收规范 |
| 格式规则 | 段落长度、对话格式 |
| 安全规则 | 内容审查 |
| 自定义规则 | 用户自由定义 |

## 2. 规则冲突裁决引擎——三阶段

### 阶段一：优先级比较

```
两规则冲突 → 比较 priority 字段
priority 高的胜出
priority 相同 → 进入阶段二
```

### 阶段二：特异性评分

```
scope 决定了 base weight：
  global (全局)        → base = 1
  volume (单卷)        → base = 2
  chapter_range (章节范围) → base = 3
  event_type (事件类型) → base = 4
  character_scene (角色场景) → base = 5
  conditional (条件式)  → base = 6

特异性 = base × dynamicCoefficient
  dynamicCoefficient:
    condition 精确匹配场景 → 1.5
    condition 部分匹配     → 1.0
    condition 不匹配       → 0（该规则不适用）

特异性高的胜出
```

### 阶段三：创建时间

```
特异性相同 → 创建时间晚的胜出（用户后定义的覆盖先定义的）
```

## 3. 反AI味——禁用词与句式检测

### 禁用词汇（出现即违规）

```
AI高频禁用词：此外/总而言之/综上所述/不可否认/显而易见/与此同时/于是/然而/不过/随即/紧接着
元叙事禁用词：本章/下一章/故事还在继续/读者/值得注意的是/需要指出的是
学术腔禁用词：从某种意义上说/一定程度上/众所周知
谄媚腔禁用词：太棒了/说得好/你完全正确/这是个好问题
模糊禁用词：似乎/也许/大概/仿佛（每500字不超过1个）
AI高频特征词：至关重要/深入探讨/强调/持久的/增强/培养/获得/突出/相互作用/复杂/复杂性
身体模板：瞳孔一缩/身体一僵/倒吸一口凉气/呼吸一滞/心头一暖/心里一沉
```

### 禁用句式

```
❌ "不是……而是……"（任何变体）
❌ "让/令/使"字句（"这一幕让他想起" → "他想起了"）
❌ "当……时"套娃句（拆成独立短句）
❌ "作为/标志着/象征着/代表着/见证了"
❌ "不仅是……更是……"
❌ 三段式堆砌（凑三个形容词、三个例子、三个排比）
```

### 六维质量矩阵

| 维度 | 检测内容 | 触发条件 |
|------|---------|---------|
| 废词率 | 禁用词出现次数 / 字数 | > 3% 标记 |
| 展示vs讲述比 | 动作描写占比 / 直接叙述占比 | < 30% 标记 |
| 视角一致性 | 是否跳 PoV | 出现即标记 |
| 描-对-动-心比例 | 四类描写的占比是否平衡 | 任一 > 50% 或 < 10% 标记 |
| 句式多样性 | 连续段落是否相同句式开头 | 连续 3 段触发 |
| 对话自然度 | 是否乒乓球式 A→B→A 对话 | 连续 5 轮触发 |

## 4. 文笔风格控制

### 风格参数

```json
{
  "povType": "third_person_limited",     // 叙事视角
  "narrativeDistance": "close",          // 叙事距离（贴着心理/中等/上帝视角）
  "avgSentenceLength": 25,               // 平均句长
  "shortSentenceRatio": 0.3,             // 短句占比（<15字）
  "longSentenceRatio": 0.15,             // 长句占比（>40字）
  "dialogueRatio": 0.35,                 // 对话占比
  "descriptionRatio": 0.25,              // 环境描写占比
  "actionRatio": 0.25,                   // 动作描写占比
  "innerThoughtRatio": 0.15,             // 内心独白占比
  "tonalMarkers": {"冷峻": 0.7, "幽默": 0.3},
  "lexicalFeatures": {"古风雅语": 0.6, "现代口语": 0.4},
  "styleDescription": "文风概括，100-200字",
  "sampleText": "代表性段落",
  "forbiddenPatterns": ["禁用词列表"],
  "forbiddenSentencePatterns": ["禁用句式正则"]
}
```

### 10 种预设风格

| 编号 | 风格 | 特征 |
|------|------|------|
| 1 | 古风仙侠 | 半文半白，注重意境，描-对-动-心 = 30/20/30/20 |
| 2 | 现代都市 | 直白口语，内心戏重，描-对-动-心 = 15/35/20/30 |
| 3 | 西方奇幻 | 史诗感，注重世界观，描-对-动-心 = 35/20/30/15 |
| 4 | 轻小说 | 大量对话，快节奏，描-对-动-心 = 10/50/25/15 |
| 5 | 悬疑惊悚 | 紧张感，慢节奏，描-对-动-心 = 30/15/20/35 |
| 6 | 热血战斗 | 动作密集，短句，描-对-动-心 = 15/10/60/15 |
| 7 | 文艺抒情 | 长句，重心理，描-对-动-心 = 25/15/10/50 |
| 8 | 幽默搞笑 | 短句，大量对话，描-对-动-心 = 10/50/20/20 |
| 9 | 极简留白 | 极短句，留白多，描-对-动-心 = 20/30/20/30 |
| 10 | 厚重史诗 | 长句，宏观叙事，描-对-动-心 = 40/15/25/20 |

## 5. 七层去AI味策略

| 层 | 内容 |
|----|------|
| 第1层 | 禁用词检测——扫描正文中是否出现禁用词汇 |
| 第2层 | 句式检测——正则匹配禁用句式 |
| 第3层 | 身体模板检测——扫描"瞳孔一缩"等模板化描写 |
| 第4层 | 模糊词密度——统计"似乎/也许/大概/仿佛"每 500 字密度 |
| 第5层 | AI 特征词检测——"至关重要""深入探讨"等高概率 AI 词汇 |
| 第6层 | 句式多样性——连续 5 句不允许相同句式 |
| 第7层 | 主语多样性——连续 3 句不允许相同主语开头 |

## 6. 实时规则检测触发

- 每 200 token 生成完毕 → 执行一次规则检测
- 检测到违规 → 通过 SSE `review_result` 事件返回前端
- 严重度分为三级：error（中断生成） / warning（标记提示） / info（仅记录）
