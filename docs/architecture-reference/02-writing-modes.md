# 写作模式完整剖析

## chapter_generate_content 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| outline_node_id | number | 可选 | - | 目标章节大纲节点ID，当前编辑章可省略 |
| 用户提示词 | string | 可选 | - | 额外写作要求，如"重点写心理活动" |
| 续写模式 | "outline"\|"content" | 可选 | "outline" | 决定生成起点 |
| 自由写作 | boolean | 可选 | true | 允许AI创造性发挥 |
| 禁止创建新实体 | boolean | 可选 | false | 禁止自动创建新角色/物品 |

## 续写模式对比

| 维度 | outline模式 | content模式 |
|------|------------|------------|
| 起点 | 章节开头（从零开始） | 前章结尾（无缝衔接） |
| 依赖大纲 | 强依赖 | 中依赖 |
| 依赖前章 | 中依赖（风格参考） | 强依赖（结尾锚定） |
| 章节独立性 | 高 | 低 |
| 适合场景 | 新场景/新时间线/新视角 | 连续事件/跨章战斗/对话延续 |
| 典型指令 | "按大纲写第3章" | "接着上一章继续" |

## 自由写作模式

**true (默认)**: AI作为"创意写手"
- 大纲是方向指引而非严格约束
- 可自行发挥战斗细节、对话互动、环境渲染
- 生成内容更丰富、更有文学性
- 适用：创作初期、需要灵感

**false (关闭)**: AI作为"执行工具"
- 严格遵循大纲摘要，不额外发挥
- 生成内容更精炼、更接近大纲原文
- 适用：大纲详细、改稿/修订阶段、精确控制

## 禁止创建新实体

**false (默认)**: 允许AI在写作中自然引入新角色/物品/地点，自动入库
**true**: 禁止创建，必须手动建角色再写作。适用：创作后期、世界已稳定

## 系统决策流程

```
用户输入 → 关键词检测("接着"/"写"/"重写") 
         → 章节状态检测(空白→outline, 有内容→content)
         → 用户明确指定(最高优先级)
         → 最终模式选择
```

## 生成流水线 (8步)

```
用户指令
  ↓
① 记忆注入层 (待兑现事项 + 主角状态档案 + 分层故事回顾)
② 上下文加载层 (前后章大纲 + 事件线 + 主角/支线事件流)
③ 实体数据注入层 (角色/物品/伏笔/势力/世界观)
④ 文笔风格匹配
⑤ AI写作面板弹出，实时流式渲染正文
⑥ 用户点「采纳/拒绝/重新生成」
⑦ 后处理 (格式/段落/标点优化)
⑧ 蒸馏入库 + 突破事件自动识别入库
```
