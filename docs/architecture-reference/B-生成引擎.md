## 1. chapter_generate_content —— 核心入口

这是整个系统唯一的正文生成入口。调用后自动执行完整流水线。

### 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| outline_node_id | int | 大纲节点 ID（必填） |
| 用户提示词 | string | 额外的写作方向指令 |
| 续写模式 | `outline` / `content` | outline=按大纲写（默认），content=接续前一章正文 |
| 自由写作 | boolean | true=AI自由发挥，false=严格遵循大纲 |
| 禁止创建新实体 | boolean | true=生成中不自动创建新角色/物品等 |

### 内部自动流程

```
1. 检查章节是否存在 → 不存在则自动创建 chapters 记录（status='writing'）
2. 加载记忆注入（→C 文档）
3. 加载上下文（→C 文档）
4. 加载实体数据
5. 加载风格控制（→E 文档）
6. 组装提示词 → 发送大模型
7. 流式返回正文 → 写面板渲染
8. 用户采纳 → 启动后处理流水线（→D 文档）
```

## 2. SSE 流式协议

### 事件类型

| 事件 | 方向 | 触发时机 | 携带数据 |
|------|------|---------|---------|
| `start` | 服务端→前端 | 生成开始 | chapter_id, estimated_tokens |
| `memory` | 服务端→前端 | 记忆注入完成后 | 注入的待兑现事项数量、角色数量 |
| `token` | 服务端→前端 | 每生成一个 token | content（单个字符/词） |
| `distillation` | 服务端→前端 | 蒸馏完成后 | 检测到的新实体/事件/伏笔数量 |
| `done` | 服务端→前端 | 全文生成完成 | 最终正文、usage 统计、nodeId |
| `error` | 服务端→前端 | 出错时 | error message |
| `resume` | 服务端→前端 | 断线重连恢复时 | 批量补发的 token |

### 断线重连

```
前端 SSE 连接断开
  → 自动重连（指数退避：1s → 2s → 4s → 8s，最多 3 次）
  → 重连时带 X-Last-Event-Id header
  → 服务端从 Redis（或内存缓存）补发自上次事件后的所有 token
  → 前端批量回放
```

### 草稿保存（生成过程中）

每 ~300 字自动保存一次草稿到 storyNode 表（content + `[PARTIAL_DRAFT]` 标记），状态为 `drafting`。生成中断后下次续写可从断点恢复。

## 3. 叙事生成引擎（LLM 内部 Prompt 层）

> 这是 B 层"生成正文"步骤在 LLM 内部的 Prompt 工程细节。

### 优先级裁决器

```
P0（最高）：用户实时指令 → 覆盖所有下层级
P1：现有大纲摘要 → 本章的故事蓝本
P2：角色状态/剧情连贯性约束 → 物理可行性保证
P3：事件流七要素 → 欲望→阻碍→行动→结果→意外→转折→结局
P4（最低）：情节脉络/伏笔表 → 背景设定
```

**规则：** P0 可覆盖 P1，但不能覆盖 P2（物理可行性——人不能在两个地方同时出现）。

### 冲突自检器

触发条件：存在前章尾段时启动。

四维比对：
1. 空间一致性——人是否回到了已离开的场景？
2. 动作一致性——是否在做已完成过的动作？
3. 时刻一致性——本章首段时刻是否严格晚于前章尾段？
4. 在场人物一致性——已离场角色是否莫名出现？

修复规则（A→D，命中即止）：
- A：无矛盾 → 正常推进
- B：时间紧邻差异 → 一句过渡桥接
- C：空间倒退/时间倒流 → 时间跳跃桥接
- D：地理硬冲突 → 重写章首衔接

### 叙事铁律

1. 信息不对称制造张力
2. 延迟揭示（每章至少 1 个不回答的信息点）
3. 钩子前置（开头先抛结果再回溯）
4. 留白（对话不说完、动机不点破）
5. 章尾制造翻页欲

章尾钩子五种类型：身份炸弹 / 认知颠覆 / 动作定格 / 倒计时 / 信息炸弹

## 4. 格式组装器（输出模板）

```
【章首衔接】（独占首行，50-120字）
⟨正文叙事段落⟩
【章尾悬念】（独占末行：具体画面 + 不可能的事实 + 戛然而止）

R|角色名|身份|标签|行动摘要
L|地点名|描述|类型|等级|所属区域
G|势力名|描述
P|道具名|类型|描述
CF|伏笔名|类型|表现|作用|操作|完成度|优先级|标签|预期回收章节
M|情绪类型|强度|说明
K|"关键台词"
EL|章节标题|摘要
T|起始时间|结束时间|事件类型
```

> 这些标记行是蒸馏入库的数据来源。系统解析 R/L/G/P/CF/M/K/EL/T 行后自动更新数据库。
